# Task Tracker API — Module 1

A minimal learning-project REST API built with Python, FastAPI, and Pydantic.
This is the Module 1 skeleton: it exposes a single health-check endpoint and no
business logic yet. CRUD, storage, authentication, and a frontend are out of
scope for this stage per the project's architecture decision (ADR).

## Requirements

- Python 3.9+
